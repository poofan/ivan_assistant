# Jarvis Assistant - Персональный голосовой ассистент

Персональный голосовой ассистент в стиле Джарвис из фильма "Железный человек" для Android и iOS.

## 🏗 Архитектура

Проект использует микросервисную архитектуру:

```
┌─────────────────┐
│  Mobile App     │ (Flutter - Android/iOS)
│  (Frontend)     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  API Gateway    │ (FastAPI - Backend Core)
│  (Orchestrator) │
└────────┬────────┘
         │
    ┌────┴────┬────────────┬──────────┐
    ▼         ▼            ▼          ▼
┌──────┐  ┌──────┐    ┌───────┐  ┌────────┐
│ STT  │  │ LLM  │    │ TTS   │  │ Skills │
│      │  │      │    │       │  │        │
└──────┘  └──────┘    └───────┘  └────────┘
```

## 🚀 Быстрый старт

### Требования
- Docker и Docker Compose
- Python 3.11+ (для локальной разработки)
- Postman (для тестирования API)

### Запуск через Docker

```bash
cd docker
docker-compose up -d
```

Сервер запустится на `http://localhost:8000`

### Локальная разработка

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## 🧪 Тестирование API

Импортируйте коллекцию Postman из `docs/jarvis_postman_collection.json`

### Примеры запросов:

**Проверка здоровья:**
```bash
curl http://localhost:8000/api/v1/health
```

**Отправка команды:**
```bash
curl -X POST http://localhost:8000/api/v1/assistant/chat \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Иван, какая погода сейчас у меня",
    "user_id": "user_123",
    "session_id": "session_001"
  }'
```

**Ответ:**
```json
{
  "text": "Сейчас посмотрю... Сейчас у вас в Москве погода +16 градусов, ветрено.",
  "action": "weather",
  "data": {
    "temperature": 16,
    "condition": "ветрено",
    "location": "Москва"
  },
  "confidence": 0.92
}
```

## 📋 Доступные команды (в разработке)

## 🛠 Технологии

**Backend:**
- FastAPI - веб-фреймворк
- Pydantic - валидация данных
- SQLAlchemy - работа с БД
- Redis - кэширование

**Базы данных:**
- PostgreSQL - основное хранилище
- Redis - кэш и сессии

**AI/ML:**
- Локальные LLM (Qwen2.5-3B, Phi-3-mini)
- Whisper/Vosk - распознавание речи
- Piper/Silero - синтез речи

**Mobile:**
- Flutter - кроссплатформенная разработка
